# Операционные системы UNIX/Linux (Базовый)

Установка и обновления системы Linux. Основы администрирования.

## Introduction

В данном проекте выполнены базовые задачи по установке, настройке и администрированию операционной 
системы Linux. Работа выполнялась на виртуальной машине (VirtualBox) с использованием Ubuntu 
20.04 Server LTS (без графического интерфейса). В рамках проекта освоены базовые консольные 
утилиты, настройка сети, управление службами и планировщик задач:  
- Установка ОС  
- Создание пользователя  
- Настройка сети ОС  
- Обновление ОС  
- Использование команды sudo  
- Установка и настройка службы времени  
- Установка и использование текстовых редакторов  
- Установка и базовая настройка сервиса SSHD  
- Установка и использование утилит top, htop  
- Использование утилиты fdisk  
- Использование утилиты df  
- Использование утилиты du  
- Установка и использование утилиты ncdu  
- Работа с системными журналами  
- Использование планировщика заданий CRON
