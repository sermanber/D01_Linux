Интерфейс lo обозначает "loopback" интерфейс. Это виртуальный сетевой интерфейс, который используется системой для связи самой с собой. Он позволяет программному обеспечению обмениваться данными через сетевые протоколы, как если бы они общались по сети. Этот интерфейс обычно использует IP-адрес 127.0.0.1 и позволяет разработчикам и системным администраторам тестировать приложения и службы без необходимости использования реальной сети.

## Part 5. Использование команды sudo
![alt text](13.png)
Добавление пользователя в группу администраторских привилегий

sudo - позволяет пользователям выполнять команды от имени другого пользователя, обычно от имени администратора системы (пользователя root). Это дает возможность выполнять администраторские задачи без необходимости входа в систему под учетной записью root, что повышает безопасность.

Объяснение команды:
- ps — команда для отображения информации о запущенных процессах.
- aux — ключи:
- a — показывает процессы всех пользователей.
- u — выводит процессы в пользовательском формате, показывая пользователя и время использования процессора.
- x — включает процессы, не связанные с терминалом.- | — используется для передачи вывода одной команды в другую.
- grep sshd — фильтрует результаты, показывая только строки с sshd.
